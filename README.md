# Real Estate Sales & Property Analytics (SQL)

## Project Overview

Real Estate Sales & Property Analytics is a SQL-based database project designed to manage and analyze real estate business data. The project focuses on organizing information about customers, properties, agents, property visits, and sales transactions to support efficient data retrieval and business analysis.

The database demonstrates the practical application of SQL concepts to solve real-world business problems and generate meaningful insights into property sales, customer behaviour, and agent performance.

## Project Objectives

- Design a structured relational database for a real estate business.
- Store and manage customer, property, agent, visit, and transaction information.
- Analyze property pricing, customer budgets, and purchasing patterns.
- Evaluate sales transactions and agent performance using SQL queries.
- Apply joins, subqueries, aggregate functions, and window functions to solve business questions.
- Generate meaningful business insights from structured real estate data.

## Tools & Technologies

- **MySQL** – Database creation, data manipulation, and analysis
- **MySQL Workbench** – SQL query development and execution
- **Relational Database Concepts** – Tables, primary keys, foreign keys, and constraints
- **SQL Queries** – Joins, subqueries, aggregate functions, views, and window functions

## Database Structure

The project uses five related tables to organize real estate data.

| Table | Purpose |
|---|---|
| Agents | Stores real estate agent information. |
| Customers | Stores customer details and purchasing budgets. |
| Property | Stores property details, locations, types, and prices. |
| Property_Visits | Records customer visits to properties. |
| Transactions | Stores property transaction and payment details. |

Primary keys and foreign keys establish relationships between the tables, while constraints help maintain data integrity.

## Business Questions Explored

The project uses 47 SQL queries to explore questions such as:

1. What are the budgets and purchasing capacities of customers?
2. Which properties have the highest and lowest prices?
3. How are properties distributed across different cities and property types?
4. What are the trends in property transactions and payment methods?
5. Which customers have visited properties, and what are their visit patterns?
6. How much time passes between a property visit and a purchase?
7. How do agents compare in terms of properties handled and sales performance?
8. How can joins, subqueries, and window functions answer complex business questions?
